    <ul>

            <code>size</code>.
        </li>
        <li>
            <strong>Type-Safe Props:</strong> All components expose their props to
            Storybook, allowing for auto-generated controls and documentation.
        </li>
        <li>
            <strong>Themeable:</strong> Easily switch themes or extend components
            with variants while keeping a consistent design language.
        </li>
        <li>
            <strong>Storybook Integration:</strong> Each component is documented in
            Storybook with examples, interactive controls, and auto-generated docs.
        </li>
    </ul>

    <h3>Getting Started</h3>
    <p>
        To use the design system in your project, import components directly from
        the package and customize them via props. For example, you can create
        buttons with different sizes and variants, and Storybook will provide
        interactive controls to explore all options.
    </p>

    <p>
        This design system aims to streamline development, enforce UI consistency,
